當沖雷達 Pro V0.5.2.1 測試版
1. 備份 GitHub 專案。
2. 將 index.html、app.js、sw.js 上傳到專案根目錄覆蓋同名檔案。
3. 不要刪除 update_data.py、data/stocks.json、.github/workflows/update-stocks.yml、manifest.webmanifest。
4. GitHub Pages 部署完成後，重新整理 Safari。
5. 在盤中頁面填入自己的 Fugle API Key，輸入 1～5 檔股票，點選「查詢 / 啟動更新」。
6. 查看報價時間是否顯示台灣年月日時分秒；觀察倒數 60 秒，待自動查詢後上次查詢時間是否變動。
7. 盤後查詢會取得最後可用報價，不代表交易正在進行。自動查詢只在盤中頁面可見時執行。
8. API Key 不會儲存在 GitHub 或 localStorage；不要分享完整金鑰。
9. 免費 API 可能有頻率限制，且盤後資料的擷取日尚非驗證交易日；評分及當沖資格需持續校驗。
